# Heat Lab for iPhone

中英双语 iPhone 主屏幕网页 App（PWA），不是签名 IPA / App Store 原生安装包。

顶部菜单可切换 English / 中文；首次使用按浏览器语言选择，之后记住选择。切换语言不会重置模拟或修改参数。

## 使用与安装

使用 Safari 打开 https://liyuxuan48.github.io/heat-lab/ ，无需登录。Safari → 分享 → 添加到主屏幕；若显示“作为网页 App 打开”，保持开启。无需 Mac 或 Apple 开发者签名。

计算由 Web Worker 在设备本地执行。初次打开需要网络；Service Worker 会尝试缓存静态页面。首次缓存失败或 iOS 清理存储都可能需要重新联网，不能保证永久离线。设置仅存当前设备；切换到后台暂停，刷新不恢复计算结果。

仅保留三维牛排模拟：可调圆润形状、锅面接触、空气对流、多次定时翻面、旋转网格、XY/XZ/YZ 温度切片、冷点定位及 CSV/STL 导出。iPhone 优先调用系统共享面板，选择“存储到文件”；不支持文件分享的浏览器使用下载链接。

## 本地运行

不需要 npm 安装：

```sh
python3 -m http.server 8765 --directory dist
```

电脑打开 http://localhost:8765 。iPhone 的主屏幕离线缓存需要 HTTPS 部署；直接点开 HTML 文件不受支持。将 `dist/` 的内容部署到任意支持 HTTPS 的静态网站即可。

## 实现

- `dist/solver.js`：Android Java 求解器的 Float64 JavaScript 移植。
- `dist/worker.js`：独立计算线程、时间推进与快照。
- `dist/app.js`、`style.css`、`index.html`：手机界面。
- `dist/i18n.js`：中英文显示、动态状态与错误提示；不改变求解器或导出数据。
- `dist/export.js`：CSV 和 STL 生成。
- `dist/sw.js`、manifest、图标：主屏幕与缓存支持。

包含单层/双层正则化算子及校准表面温度重构。不是 Julia 原始 Neumann 约束算法；保留 Android 版的网格误差与辅助域数值热交换。详见应用内“方法”。

## 验证范围

Java/JavaScript 相同算例（8 个厚度网格，60 s，17.123 和 40.987 s 翻面）：完整网格温度、所有表面温度、锅/空气热功率和数值域能量的最大绝对差为 **1.11697e−11**。不同物理量混合比较的这个数值只用于实现一致性，不是物理误差界限。

独立球体 Robin 解析解比较（12 网格、Fo=0.1、r≤R/2）RMS：Bi=0.1 为 0.001589921，Bi=1 为 0.006995353，Bi=10 为 0.060376336。翻面瞬间场连续、非零均匀平衡及无效参数检查通过。

四种导出格式的内容单测通过，包括接触面翻转坐标、Robin 热流关系和面积积分热功率。

在本地 Chromium 浏览器以 390×844 手机视口检查了布局、设置、双次翻面完成、切片、冷点定位、暂停/继续及安装说明。WebMCP 两个可选工具注册、有效配置读回及无效输入拒绝已验证。浏览器自动化未获得下载事件，因此不将下载或 iOS 系统分享面板视为已实机验证。没有可用的 iPhone / iOS 模拟器；Safari 真机安装、性能和离线缓存仍需实机确认。

默认 600 s 浏览器算例（中途暂停/继续一次）完成：1 次翻面，内部最低 50.494143 °C、最高 120.134423 °C、平均 80.826874 °C。暂停时间造成额外短时间步，结果允许与连续运行略有不同。

英语支持：自动测试覆盖静态界面、错误信息、动态诊断数字保留和语言选择。在本地 390×844 浏览器验证了切换语言时保留已编辑参数和完成结果、英语校验提示以及刷新后语言偏好保留。未在 iPhone 真机验证。
